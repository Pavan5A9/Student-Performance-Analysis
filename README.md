# 📖 About the Project

Educational institutions generate large amounts of academic data every semester. Manually calculating average marks, assigning grades, and analyzing student performance is often time-consuming and prone to errors.

This project automates the entire process using Python. It reads student data from a CSV file, performs exploratory data analysis, calculates average marks, assigns grades according to predefined criteria, and visualizes performance using attractive charts.

The project demonstrates the fundamental concepts of **Data Analytics**, making it ideal for beginners learning Python, Pandas, and data visualization techniques.
